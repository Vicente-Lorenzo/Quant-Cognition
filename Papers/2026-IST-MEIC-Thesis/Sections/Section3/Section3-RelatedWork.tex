This section reviews the published work on deep reinforcement learning applied to financial trading. The review was carried out in two stages. Surveys were read first, to establish which problems the field treats as open and which papers are worth reading in full. Individual articles were then read and their design decisions recorded in a common format, so that studies using different markets and different algorithms could be compared on the same terms.

Eighteen articles were examined in that way. Their basic features are collected in \Cref{Tables:BasicRelatedWork} and the design decisions inside each agent in \Cref{Tables:AdvancedRelatedWork}, and the discussion below refers to both throughout.

The studies reviewed here answer the question of whether a deep reinforcement learning agent can learn a profitable trading policy. They say much less about the conditions under which that answer holds, because the environment each agent was trained in is usually described in a sentence or two and is rarely reproducible from the description given.

That environment is the part this work had to build before the question could be asked. An agent trained against a simplified market learns to exploit the simplification, so the worth of any result depends on how the environment charges for trading, advances time and fills orders. \Cref{Chapter:Implementation} describes that environment and the agent that runs inside it.
